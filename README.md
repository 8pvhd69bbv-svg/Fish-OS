# FLYS FOR FISH — Fish OS

Fish OS is a private fishing operating system for managing:

- Fishing trips
- Journals
- Fish
- Locations
- Gear
- Rods
- Reels
- Lines
- Fly patterns
- Fly tying materials
- Inventory
- Packing
- Research
- Maps
- Photos
- Video
- Purchases
- Warranties
- Podcast notes
- Tracking

## Deployment

The application is hosted through GitHub Pages.

Private user data is stored through Supabase authentication and
account-scoped storage.
